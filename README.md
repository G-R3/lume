# Lume

Lume is a desktop music player for audio files on your computer. Add folders to build a library and play tracks in place.

## Features

- Plays FLAC, M4A, MP3, AAC, OGG, OPUS, and WAV files.
- Filters and sorts tracks, with artwork and audio metadata.
- Creates playlists and lets you like tracks.
- Manages a playback queue with shuffle, seeking, and volume controls.
- Rescans folders and remembers your playback session.

## Run locally

```sh
pnpm install
pnpm dev
```
